# Studio Pipeline

Welcome to the **Studio Pipeline** documentation! This project provides a comprehensive pipeline for studio workflows using **Shotgrid (Flow) Toolkit** and **Blender**.

## 🎯 Overview

This studio pipeline integrates:

- **Shotgrid Toolkit** - Production tracking and asset management
- **Blender** - 3D creation and animation
- **Python** - Pipeline automation and tools

## ✨ Features

- **Shotgrid Integration**: Seamlessly connect with Shotgrid for asset tracking, task management, and production data
- **Blender Tools**: Custom Blender add-ons and scripts for studio workflows
- **Automated Pipeline**: Python-based automation for rendering, asset publishing, and file management
- **Extensible Architecture**: Modular design for easy customization and extension
